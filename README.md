# Portafolio Personal

Portafolio profesional responsive con diseño moderno y secciones integradas.

## Estructura

- `index.html` - Página principal
- `css/` - Hojas de estilo (main.css, responsive.css, variables.css)
- `js/` - Scripts (main.js, animations.js, form.js)
- `images/` - Imágenes y media
- `assets/` - Fuentes, iconos y recursos adicionales

## Desarrollo

Abrir `index.html` en el navegador o usar un servidor local.
